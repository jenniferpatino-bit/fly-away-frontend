# Fly Away – Frontend

SPA en React 19 + TypeScript + Vite que consume la API de reserva de vuelos Fly Away.

Incluye registro, login (con nombre del usuario), búsqueda con filtro de fechas, reservas con detalle, "Mis reservas", logout y rutas protegidas.

## Cómo correrlo

1. Levanta el backend en `http://localhost:8080` (`./mvnw spring-boot:run` en su carpeta).
2. En esta carpeta:

```bash
npm install
npm run dev
```
